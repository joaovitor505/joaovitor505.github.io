# Página Pessoal

Página pessoal em HTML e CSS, com uma apresentação sobre mim, minha formação, habilidades e projetos.

Acesse online: https://joaovitor505.github.io/NOME-DO-REPOSITORIO

 O que tem na página

- Sobre mim
- Formação
- Habilidades
- Projetos, com link para o GitHub de cada um
- Contato

 Tecnologias usadas

- HTML
- CSS
- GitHub Pages 

 Como ver no seu computador

1. Clone o repositório ou baixe os arquivos
2. Abra o arquivo `index.html` no navegador

 Estrutura do projeto

- `index.html`: estrutura e conteúdo da página
- `css/style.css`: estilo e visual da página

 O que aprendi fazendo esse projeto

- Como estruturar uma página com HTML, usando seções, listas e links
- Como separar o estilo em um arquivo CSS e conectar ele ao HTML
- Como usar classes no CSS para estilizar blocos específicos
- Como publicar uma página na internet com o GitHub Pages
